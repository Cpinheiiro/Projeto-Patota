# Patota de Sexta

Site da minha patota de futebol. Jogamos toda sexta e a confirmação de presença hoje é feita no grupo do WhatsApp. Quero trocar isso por um site.

Projeto em desenvolvimento. Estou usando ele para praticar o que aprendi no Dev-Burger, agora num projeto só meu.

## O que já tem

- Tela de login com validação de formulário (React Hook Form e Yup)
- Visual criado no Google Stitch e levado para o Figma

## O que vem agora

- Home, lista de jogadores com contato e confirmar presença
- Rotas entre as páginas
- Back-end em Node.js e Express, com banco PostgreSQL
- Login com autenticação JWT
- Front-end conectado à API, puxando os dados do banco
- Assistente virtual com IA, integrado por API, que tira dúvidas e também agenda jogos: a pessoa pede (dia, hora e local), o assistente monta o agendamento e mostra uma tela para confirmar antes de criar

## Tecnologias

- Front-end: React, Vite, Styled Components, React Hook Form, Yup e React Router
- Back-end (planejado): Node.js, Express, PostgreSQL e JWT
